# Banking Analytics Dashboard | Power BI

## Project Overview
This project presents an interactive banking analytics dashboard developed using Microsoft Power BI. It helps analyze banking transactions, loan payments, card usage, branch performance, and customer support operations.

## Objectives
- Analyze revenue and transaction performance across branches.
- Monitor loan payments and overdue amounts.
- Understand credit and debit card usage.
- Track customer support tickets by category and status.
- Present key performance indicators through interactive visualizations.

## Tools & Technologies
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and KPI calculations
- Data Visualization and Dashboard Design

## Dashboard Features
- Revenue by Branch
- Loan Payment Analysis
- Overdue Payment Monitoring
- Card Type and Transaction Analysis
- Top Merchants and Cardholders
- Open vs. Resolved Support Tickets
- Interactive filters and slicers
